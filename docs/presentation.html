How it's built: AI extracts, code decides.

Stack
  • Next.js 16 + React 19 + TypeScript, Tailwind, Leaflet on a keyless Esri basemap.
  • One Zod contract (lib/schemas.ts) validates every API request and response.
  • SQLite + Drizzle, rebuilt offline from committed data in about a second.
  • 71 unit tests (Vitest): ranking, lease checks, rent split, deposit math.
Deterministic ranking
  • Priority weights 2^-(rank-1); score = weighted average of 12 explainable criteria.
  • Commute uses real class buildings + GTFS stops; cost adds utility and parking estimates.
  • Every partial or unknown criterion becomes a plain-English shortfall. Nothing hidden.
Grounded AI (Claude or Gemini)
  • The LLM only extracts: chat answers, Backpack classes, lease clauses.
  • Lease flags must quote the lease verbatim and map to a fixed list of cited rules.
  • Deposit and fee caps are checked by arithmetic. Works fully offline in mock mode.
Data & privacy
  • Pipeline: U-M listings (by hand), Census geocoder, TheRide + U-M GTFS, OSM, City construction layer, Census ACS.
  • Rent splitter: envy-free prices via Bellman-Ford on difference constraints.
  • Deposit vault: IndexedDB + SHA-256 on the student's device. Nothing stored on our side.

Calm UX. Grounded math. Zero data stored.

  • Live today: 50 listings (3 real, 47 labeled mock), 54 U-M buildings, 867 TheRide & Blue Bus stops, 563 OSM places, live City of Ann Arbor construction data, and a Census student-population overlay.
